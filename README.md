# Deepak Portfolio

A personal portfolio website built to showcase projects, skills, certifications, and contact details.

## Live Demo

- https://deepak-portfolio-red.vercel.app/

## Features

- Responsive single-page portfolio layout
- Project showcase with button links
- Skills and certifications sections
- Contact form that opens the user's email client
- Resume button in the profile card

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Main portfolio page
- `styles.css` - Site styling
- `script.js` - Scroll and contact form behavior
- `Galary/` - Profile and gallery images

## Notes

The site is deployed on Vercel at the live demo link above.
